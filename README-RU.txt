FILKO JARVIS v0.1

Это исходный проект Android-приложения.

ВАЖНО ДЛЯ ЗАГРУЗКИ В GITHUB:
1. ZIP-архив нельзя просто загрузить в репозиторий и ожидать, что GitHub распакует его.
2. Нужно извлечь содержимое архива, сохранив структуру папок, и загрузить файлы/папки проекта в корень репозитория.
3. Файл .github/workflows/build.yml должен оказаться именно по пути .github/workflows/build.yml.
4. После загрузки открой вкладку «Действия» (Actions) и дождись сборки.

Первая версия использует системные сервисы распознавания речи и синтеза речи Android.
Русский язык зависит от установленных на телефоне голосовых и речевых сервисов.
Постоянное прослушивание, ChatGPT и облачная память пока не реализованы.

Для сборки используется Android Gradle Plugin 8.7.3 и Gradle 8.9.
